# Stretch Daily

A native Android mobility coaching app. Generates personalized 10–15 minute daily stretching and tendon-strengthening routines based on monthly benchmark assessments.

## Tech Stack

- Kotlin + Jetpack Compose
- Room (local database, fully offline)
- Hilt (DI)
- Min SDK 30 (Android 11)
